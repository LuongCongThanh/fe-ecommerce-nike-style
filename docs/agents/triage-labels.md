# Triage labels

The engineering skills use five canonical triage roles. This table maps those
roles to the label strings used by this repository.

| Canonical role    | Tracker label     | Meaning                                           |
| ----------------- | ----------------- | ------------------------------------------------- |
| `needs-triage`    | `needs-triage`    | A maintainer needs to evaluate the issue          |
| `needs-info`      | `needs-info`      | More information is required from the reporter    |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an autonomous agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgment         |
| `wontfix`         | `wontfix`         | The issue will not be actioned                    |

When a skill mentions a triage role, use the corresponding tracker label from
this table. Update the tracker and this table together if the label vocabulary
changes.
