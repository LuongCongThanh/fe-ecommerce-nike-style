# Fashion Storefront UI Director

Project-scoped agent/skill for customer-facing UI/UX work in this Next.js
storefront. Its executable instruction source is:

- Codex and Agent Skills: `.agents/skills/fashion-storefront-ui-director/SKILL.md`
- Claude Code entry point: `.claude/skills/fashion-storefront-ui-director/SKILL.md`

It coordinates the installed design skills selectively, preserves the design
contract in `design.md`, and applies 3D only as an optional, fault-tolerant
campaign/hero enhancement.

## Invocation

- Codex: `$fashion-storefront-ui-director redesign the mobile product detail page`
- Claude Code: `Use fashion-storefront-ui-director to improve the catalogue filters`

Start a new assistant session after adding the skill so the host discovers it.
