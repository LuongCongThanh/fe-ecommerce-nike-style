# Xây front-end trước bằng MSW + localStorage cho module chưa có API backend

Nhiều module còn thiếu (Wishlist, Coupon, Promotion, Banner, Reports, Admin Users, Admin Orders list, và cả Category/Product write API — hiện là `ReadOnlyModelViewSet`) chưa có model/API tương ứng ở backend Django, kể cả những phần chỉ cần sửa rất mỏng. Chúng tôi quyết định **không** chờ backend hay dựng Next.js Route Handlers riêng, mà tái dùng MSW (đã là devDependency, đã dùng cho test) để chặn các request này ở front-end, với thao tác ghi lưu vào `localStorage` để không mất dữ liệu khi reload. Lý do: đây là dự án portfolio ưu tiên hoàn thiện bề rộng hệ thống trước, front-end không nên bị chặn bởi tiến độ backend; tái dùng MSW giữ nhất quán với pattern test hiện có thay vì thêm một cơ chế mock mới song song. Khi backend có API thật, tắt handler MSW tương ứng mà không cần đổi code gọi API ở tầng UI, miễn contract khớp.
